# Pixel Meteor Dash — Android WebView Test Wrapper (BUILD-002)

## Source integrity
`app/src/main/assets/index.html` is copied byte-for-byte from the supplied DEV-004 file.
Do not edit this file as part of wrapper work.

## Build locally
Requirements: JDK 17, Android SDK (API 35), Gradle 8.9.
Run:
```bash
gradle --no-daemon :app:assembleDebug
```
APK output:
`app/build/outputs/apk/debug/app-debug.apk`

## Cloud build (phone-friendly)
1. Create a private GitHub repository.
2. Upload the complete contents of this folder to the repository root.
3. Open Actions → Android Debug APK → Run workflow.
4. Wait for the job to finish successfully.
5. Open the run's Artifacts section and download `pixel-meteor-dash-webview-test`.
6. Extract `app-debug.apk` and install it on the Android test phone.

The workflow does not sign a release build and does not use a private signing key.
